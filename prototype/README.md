# Созвездие двоих: прототип

Кликабельный прототип сайта-подарка для пары. Все данные вымышлены («Тимур и Алина»), в продукте они приходят из конструктора.

## Как открыть

```bash
cd prototype && python3 -m http.server 8000
# http://localhost:8000
```

Короткие ссылки сразу на экран: `#home`, `#meet`, `#chat`, `#sky`, `#worlds`, `#capsule`, `#letter`.

## Что внутри

- **Конверт → письмо.** Печать ломается искрами, письмо «пишется» пером.
- **Вселенная.** Живое небо вращается вокруг Полярной. Частицы собираются в монограмму, потом перетекают в созвездие глав. Таймер «вместе» переключается по нажатию: дни, годы/месяцы, часы, удары сердца.
- **Глава I: первая встреча.** Золотой слой стирается пальцем, под ним фото.
- **Глава II: переписка.** Чат в стиле Telegram и статистика по экспорту чата (пример).
- **Глава III: небо той ночи.** Настоящая карта неба на дату и город: каталог Hipparcos до 5.3m, Луна и планеты через astronomy-engine, ссылка на снимок NASA APOD за этот день.
- **Глава IV: наши миры.** Места под AI-кадры пары в разных стилях.
- **Глава V: капсула времени.** Письмо, которое откроется в заданную дату.

## Источники данных

- `sky-data.js`: звёзды, линии и названия созвездий из [d3-celestial](https://github.com/ofrohn/d3-celestial) (BSD-3-Clause).
- Эфемериды Луны и планет: [astronomy-engine](https://github.com/cosinekitty/astronomy) (MIT), подключается с jsDelivr.
