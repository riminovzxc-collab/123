# Созвездие двоих: прототип

Кликабельный прототип сайта-подарка для пары. Все данные вымышлены («Тимур и Алина»), в продукте они приходят из конструктора. Вместо фото и видео стоят процедурные иллюстрации-заглушки.

## Как открыть

```bash
cd prototype && python3 -m http.server 8000
# http://localhost:8000
```

Короткие ссылки сразу на экран: `#map`, `#dates`, `#photos`, `#videos`, `#us`, `#film`, `#m-<id>` (воспоминание, например `#m-wedding`), `#sub-<name>` (`chat`, `sky`, `when`, `dreams`, `capsule`, `worlds`).

Однофайловая сборка (для публикации): `python3 build.py dist/sozvezdie.html`.

## Что внутри

- **Конверт → письмо.** Печать ломается искрами, письмо «пишется» пером, частицы собираются в монограмму «Т·А».
- **Карта.** Граф из 28 воспоминаний в пяти созвездиях: «Начало», «Дороги», «Дом», «Праздники», «Будущее». Двигается пальцем или мышью, масштаб щипком или колёсиком, у каждого созвездия своя кнопка. При наведении подсвечиваются связанные звёзды. Подписи раскладываются так, чтобы не наезжать друг на друга.
- **Полёт по звёздам.** Карточка воспоминания со свайпом вперёд и назад. Камера пролетает между звёздами со штрихами «варпа». При переходе в новое созвездие появляется его название. Есть полоса-навигатор по созвездиям и автополёт.
- **Карточка воспоминания.** В ней:
  - фотокарусель и видео;
  - «его версия / её версия»;
  - цифры поездки;
  - встроенные блоки: стирание, переписка, настоящее небо в эту минуту, капсула;
  - связанные воспоминания.
- **Вкладки.**
  - «Даты»: «в этот день N лет назад», ближайшие годовщины и дни рождения с обратным отсчётом, хронология с фильтрами. Каждая дата открывает своё воспоминание на карте.
  - «Фото»: сравнение «тогда и сейчас», сетка с фильтрами, просмотр с переходом к воспоминанию.
  - «Видео»: «Наш фильм» по всем воспоминаниям, истории как в Instagram, короткие ролики.
  - «Мы»: письмо, переписка в цифрах, небо четырёх наших ночей, «Открой, когда…», мечты с галочками, капсула времени, наша песня, AI-миры.

## Файлы

- `data.js` — контент пары: воспоминания, созвездия, связи, письма, мечты.
- `scenes.js` — генератор кадров-заглушек и их анимации для «видео».
- `app.js` — вся логика: небо, частицы, карта-граф, полёт, вкладки, просмотрщики.
- `styles.css`, `index.html` — оформление и разметка.
- `sky-data.js` — звёзды, линии и названия созвездий из [d3-celestial](https://github.com/ofrohn/d3-celestial) (BSD-3-Clause).
- Эфемериды Луны и планет: [astronomy-engine](https://github.com/cosinekitty/astronomy) (MIT), подключается с jsDelivr.
